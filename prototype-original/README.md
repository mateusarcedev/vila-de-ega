# Memórias de Tefé

Protótipo estático, responsivo e sem dependências de build.

## Prévia local

Abra `index.html` no navegador ou sirva esta pasta com um servidor estático, por exemplo:

```sh
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Interações incluídas

- Alternância entre viagem guiada e exploração livre, sem reiniciar o capítulo atual.
- Portais de época, navegação fixa da linha do tempo e indicador do período ativo.
- Fichas demonstrativas de acontecimento, personagem, lugar e fontes.
- Área visual substituível para uma futura cena 3D, com alternativa ilustrada e controle de movimento.
- Menu móvel, suporte a teclado e preferência por movimento reduzido.

As ilustrações do protótipo são desenhos vetoriais e CSS originais, identificados como artísticos ou esquemáticos. Nenhuma fotografia de terceiros foi incluída. As datas e nomes ainda sem referência estão assinalados como pesquisa em andamento.
